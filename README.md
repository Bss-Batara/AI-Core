# AI-Core Local Agent

AI-Core adalah coding agent lokal untuk menjalankan local AI brain, autonomous planner, project memory, file intelligence, coding agent, debugging, controlled terminal, Git, VS Code, dan GitHub integration.

## Menjalankan

Pastikan Ollama aktif dan model tersedia:

```powershell
python main.py
```

## Validasi

```powershell
python -m unittest -v
```

Perintah CLI: `/files`, `/read <path>`, `/status`, dan `exit`.
